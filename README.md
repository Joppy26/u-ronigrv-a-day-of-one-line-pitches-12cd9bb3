## The pitch

> Your app idea deserves more than a notes app: tell it to my AI agent in plain words and watch it build the first version on make.fun for free, no coding needed, and the idea stays yours.

One sentence, written for a friend who has never coded: a concrete reason
to say yes now (watch the first version get built, free), no jargon, no
overpromising, and the idea stays theirs.

**Character count: 186** (limit 240). Verified by running `main.ts` twice:
both runs produce byte-identical output.

## How it works

`main.ts` writes the pitch above to `/output/entry.txt`, exactly as written,
with nothing added. Run it with Node 22 or later:

```sh
node main.ts
```
